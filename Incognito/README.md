<p>
Discord tracks almost every interaction. Incognito blocks telemetry, usage profiling, crash reports, and process scanning, spoofs the fingerprint data that's safe to fake, and hides client mods. It also hides typing and read status, disables idle detection, strips trackers from sent and copied URLs, and randomises filenames and strips image metadata on upload. Every feature is individually toggleable in settings.
</p>

<p>
Blocking read receipts is off by default to avoid confusion: viewing messages sends zero read-status requests to Discord, which also means channels, DMs, and mentions will reappear as unread after a restart. You can enable it in settings if you want it.
</p>
